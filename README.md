# sales-analytics-app-streamlit
# 💼 Sales Analytics App

Aplicativo interativo de análise de vendas desenvolvido com **Python** e **Streamlit**.  
O projeto permite visualizar métricas de vendas, gerar relatórios dinâmicos e manipular os dados de forma simples e intuitiva.

---

## 🚀 Tecnologias Utilizadas
- Python
- Streamlit
- Pandas
- Plotly
- Altair

---

## 📊 Funcionalidades
- Visão geral de vendas com dashboards interativos  
- Visualizações dinâmicas e personalizadas  
- Exibição de tabelas filtradas  
- Adição e remoção de registros de vendas  
- Interface amigável e responsiva
